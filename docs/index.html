Your meetings stay on your Mac.

Speech recognition and translation run locally on Apple Silicon. Once the models are downloaded, MimiVox works fully offline.

  • No cloud, no accountsNo audio or text ever leaves the machine.
  • No recordings keptMeeting audio isn't saved — just the transcript.
  • Retention you chooseKeep transcripts forever, for a week, or not at all.

Up and running in three commands.

Build the app, open Home, and download the caption models (about 1.7 GB).

  • Apple Silicon
  • macOS 14+
  • Xcode 26+
  • uv
$ brew install uv ffmpeg
$ git clone https://github.com/alok-19/mimivox && cd mimivox
$ make app   # builds and opens MimiVox.app

No meeting handy? Run make fixture and pick the Replay source.
